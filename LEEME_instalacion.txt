MIS VIÁTICOS V0.5.1 · PDF + FOLIOS + TOTALES

CAMBIOS
- Folio opcional: propone candidatos tras FOLIO / TICKET, junto a fecha y bajo códigos de barras. Solo se llena tras tocar una opción.
- Total: detecta TOTAL, GRAN TOTAL, TOTAL M.N., etc. Nunca se guarda sin verificación.
- Archivos PDF: adjuntar archivos descargados, extraer texto y OCR de páginas escaneadas.
- Comprobantes PDF de 1 a 12 páginas y máximo 25 MB por archivo.
- PDF final reúne las imágenes de todas las páginas; el Excel mantiene 1 fila por gasto.
- Modo oscuro, PDF equilibrado y navegación Liquid Glass preservados.

PREPARACIÓN DEL LECTOR PDF LOCAL (una sola vez en tu Mac)
1. Descarga/descomprime paquete V0.5.1 PWA.
2. Abre Terminal en esa carpeta.
3. Ejecuta bash preparar_pdf_local.command (se requiere Node.js y npm e internet para esta etapa).
4. Confirma que se creó pdfjs/ready.json y los 2 módulos .mjs.
5. Copia index.html, sw.js, manifest.webmanifest, carpeta pdfjs y los demás archivos actualizados a tu clon de GitHub mis-viaticos. Conserva la carpeta OCR ya publicada.
6. GitHub Desktop → Commit to main → Push origin.
7. En los teléfonos, con internet abre la PWA y permite actualizar; la instalación almacena pdfjs y OCR para uso sin conexión.

PRUEBAS RECOMENDADAS
- Ticket con TOTAL M.N., GRAN TOTAL y cambio o subtotal.
- Folio al lado de fecha y folio después de TICKET:.
- PDF con texto digital (Uber) y PDF de 2 páginas escaneadas.
- Modo avión: abrir PDF, extraer y exportar PDF + Excel.
- Restaurar respaldo JSON y comprobar que se preservan páginas PDF.

NOTAS
- Los PDF originales se rasterizan a JPEG legible para integrar las páginas al PDF de comprobantes. Esto no preserva la capa de texto seleccionable del PDF original.
- Folios impresos debajo de un código de barras pueden sugerirse; decodificación binaria del código de barras no está garantizada.
- La extracción de folios/razón social/importe puede fallar en tickets de baja calidad. Confirma siempre.
- No desinstales la PWA ni borres datos: respalda JSON antes de actualizar.
